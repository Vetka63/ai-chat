# Mock Games Server · День 18-v2

Самостоятельный Java 21 / Spring Boot сервис — единственный владелец каталога
игр. Использует файловую SQL-базу H2 в Docker-томе mock-games-data.
Таблица seed_games содержит прежние игры для сценария дня 17;
generated_games хранит **все** автоматически созданные игры без удаления
старых записей.

GameGenerator создаёт одну вымышленную игру при старте и затем каждые
120 секунд. Интервал задаётся GAMES_GENERATION_INTERVAL_MS. REST API:

- GET /games?query=космос — поиск по каталогу, совместимый с днём 17;
- GET /games/latest?after_id=0&limit=10 — не более десяти *новых после
  курсора* игр, упорядоченных от самой новой; latest_id равен ID самой новой
  действительно возвращённой игры (или входному курсору для пустого списка);
- GET /health — проверка доступности.

Предел «10» относится только к порции, которую MCP передаёт агенту для
одной сводки. В SQL-базе могут быть сотни игр. Если между двумя сводками
появилось более десяти, в выпуск входят десять самых новых; другие
игры остаются в базе и доступны обычному поиску.

Сервис не знает о чатах, подписках, агенте и MCP. Java MCP java-mcp-games
вызывает его HTTP API и предоставляет инструмент get_new_games.

Проверка: docker compose -p ai-chat-day-18-v2 up -d --build agents-client
game-feed-worker, затем откройте http://localhost:8084/games/latest?after_id=0.
Через две минуты latest_id увеличится, при этом старые игры останутся в базе.
В Docker сборка проекта выполняет тесты.
