# Подключаемые слои памяти

Этот пакет не знает об алгоритмах и модели-провайдере.

- `models.py`: сообщения с ID, запись/предложение, task/profile, workspace,
  команды изменения с ожидаемыми версиями.
- `contracts.py`: MemoryRepository (порт хранения) и MemoryWritePolicy
  (предметные правила конкретного агента).
- `service.py`: LayeredMemory нормализует ввод, применяет политику и поручает
  атомарную запись репозиторию.

Границы данных: краткосрочная память принадлежит чату, рабочая — задаче,
долговременная — паре агент/профиль. Предложения находятся отдельно и не считаются
памятью до подтверждения. Другие агенты могут подключить эти контракты и собственные
политики. Общее хранилище не означает общие промпты или автоматический обмен знаниями.

SQLite-реализация проверяет принадлежность и версии внутри транзакций.
API не принимает произвольные имена таблиц или выбираемый клиентом profile_id.
Сейчас это локальное приложение: реальную аутентификацию потребуется добавить
до публикации многопользовательского сервиса.
