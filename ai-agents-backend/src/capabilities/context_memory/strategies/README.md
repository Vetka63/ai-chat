# Стратегии контекста

Каждый класс в этой папке реализует маленькую самостоятельную политику формирования
LLM-контекста. Общий DTO входа — `ContextRequest`, выхода — `PreparedContext`.

- `full.py` — контрольная полная история.
- `sliding_window.py` — точный хвост из N сообщений.
- `sticky_facts.py` — key-value память плюс хвост.
- `branching.py` — история только выбранной независимой беседы.
- `summary.py` — совместимая стратегия сжатия Дня 9.
- `common.py` — единственный построитель `system + history + current user`.

Стратегия не вызывает основной диалоговый completion. Она может создать только
свои служебные runs (summary/facts), а затем возвращает готовый контекст агенту.
Это разделение не позволяет алгоритму памяти обойти output policy агента.
