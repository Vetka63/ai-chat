# Персонализация

Подключаемая возможность, независимая от предметной области агента.

- `models.py` — строгие Pydantic-модели профиля, предпочтений и команд создания/обновления.
- `contracts.py` — порт `ProfileRepository`; реализация SQLite находится в infrastructure.
- `context.py` — представление имени и предпочтений для LLM без служебных ID и версий.

Профиль хранится отдельно от сообщений, рабочей и долговременной памяти.
`revision` версионирует имя/предпочтения, `memory_revision` — долговременные записи.
Редактирование требует ожидаемой версии и не вызывает LLM. Конфликт возвращает 409.
Новый профиль не копирует память другого. Профили — локальные персоны, не аккаунты.

Агент сам решает, где подключать данные. `algorithm_coach` включает их в обычные
и служебные запросы и сохраняет полный снимок в метриках. Привязка задачи фиксирована.
Свободный текст предпочтений не получает полномочий системной инструкции.
Проверка версии перед публикацией не даёт незаметно принять ответ для старого профиля.
