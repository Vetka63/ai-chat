# Application

Это внешний слой приложения:

- `main.py` описывает HTTP-маршруты и жизненный цикл FastAPI;
- `bootstrap.py` связывает адаптеры с агентами;
- `settings.py` читает секреты и процессные настройки из окружения;
- `api_models.py` содержит DTO, существующие только на HTTP-границе.

Контроллер запуска не строит LLM-сообщения и не управляет контекстом. Он получает
агента из `AgentRegistry` и вызывает `run()`. CRUD-маршруты диалогов работают с
общим портом `ConversationStore`, всегда предварительно проверяя `agent_id`.
