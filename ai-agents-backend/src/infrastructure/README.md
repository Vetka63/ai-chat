# Инфраструктура

Заменяемые технические адаптеры без предметных правил агента:

- completions.py / deepseek.py — нормализация HTTP-ответов, usage и ошибок провайдера.
- model_catalog.py — разрешённые модели, маршрутизация и снимки тарифов.
- tokenizers.py — официальный Mistral tokenizer и приблизительная оценка DeepSeek.
- sqlite_store.py — оригинальные messages, настройки чата и независимое копирование истории.
- sqlite_usage.py — отдельные запуски purpose=dialogue/summary/facts, их статусы и расходы.
- sqlite_summary.py — отдельный актуальный снимок сводки каждого диалога.
- sqlite_facts.py — актуальная key-value память каждого диалога.
- sqlite_branching.py — checkpoint и атомарное создание двух независимых бесед.

Вопрос сохраняется ДО вызова модели/сжатия, ответ — отдельной транзакцией после проверки.
Сводка заменяется атомарно после успешного сжатия, исходные сообщения не удаляются.
Чтение/изменение ограничены agent_id. Удаление диалога каскадно удаляет messages,
runs, summary, facts и принадлежащие ему checkpoints. Миграция добавляет старым
чатам context_settings=full и метаданные дерева без изменения истории.

В Docker база /app/data/agents.sqlite3 лежит в именованном томе. Один процесс uvicorn:
для нескольких workers нужны межпроцессные блокировки и lease незавершённых запусков.
SQLite заменяется реализацией портов ConversationStore, UsageRepository, SummaryRepository.
