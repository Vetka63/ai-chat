# Инфраструктура

Пакет содержит заменяемые технические адаптеры и не определяет поведение агента.

- `deepseek.py` реализует порт `LlmClient` через HTTP API DeepSeek.
- `sqlite_store.py` реализует порт `ConversationStore` через SQLite.

SQLite хранит таблицу диалогов и упорядоченную таблицу сообщений. Все операции
чтения и удаления дополнительно ограничены `agent_id`, поэтому идентификатор
чужого чата не позволяет другому агенту получить его контекст. Успешная пара
`user/assistant` добавляется одной транзакцией; ответ, не прошедший валидацию,
не сохраняется.

В Docker файл базы находится в `/app/data/agents.sqlite3`, а каталог `/app/data`
подключён к именованному volume. Реализацию можно заменить PostgreSQL или внешним
REST-хранилищем без изменения `DialogueAgent`.
