# Диалоговый агент

Это отдельная сущность задания Дня 6, а не обёртка контроллера над одним HTTP-вызовом.

## Как проходит запрос

1. `DialogueAgent.run()` принимает только `AgentCommand` с полем `message`.
2. `TrimInputPolicy` удаляет внешние пробелы.
3. Входные валидаторы отклоняют пустой или слишком длинный текст до вызова API.
4. Агент сам добавляет закрытый от клиента системный промпт и формирует два
   сообщения: `system` и текущий `user`.
5. Через интерфейс `LlmClient` агент вызывает DeepSeek.
6. Выходная политика очищает ответ, а валидатор проверяет, что он не пуст.
7. Агент возвращает унифицированный `AgentResult`.

Основой `prompts/system.txt` служит базовый системный промпт профиля `general`
из Java-проекта. Дополнительная строка фиксирует фактического API-провайдера
DeepSeek и запрещает модели придумывать принадлежность к Gemini или ChatGPT.

Начиная с Дня 7, история загружается сервером из SQLite. Клиент передаёт только
`conversation_id` и новое сообщение. `FullHistoryContextPolicy` строит запрос в
порядке `system → сохранённые user/assistant → новый user`. После сборки контекста
новое сообщение пользователя сразу сохраняется, а ответ ассистента добавляется
только после успешного вызова и проверки. Поэтому сбой внешней LLM не стирает
вопрос пользователя, но ошибочный или пустой ответ в историю не попадает.

Диалоговый агент явно отправляет DeepSeek настройку
`thinking: {"type": "disabled"}`. У моделей V4 режим рассуждений включён по
умолчанию и способен потратить весь `max_tokens` на `reasoning_content`, не успев
сформировать видимый `content`. Для универсального чата используется обычный
режим ответа; агенты, которым нужны рассуждения, смогут включить его отдельно со
своим подходящим бюджетом токенов.

## Как добавить следующего агента

Создайте соседний пакет `src/agents/<id>` со своими `config`, `agent`, `factory`,
промптом, политиками и валидаторами. Реализуйте общий контракт `Agent` и добавьте
готовый экземпляр в `AgentRegistry` внутри `application/bootstrap.py`.

Если этому агенту позднее понадобятся structured output или LLM-as-judge, их
реализации следует положить в его пакет. В общее ядро выносится только интерфейс,
который действительно понадобился нескольким агентам.
