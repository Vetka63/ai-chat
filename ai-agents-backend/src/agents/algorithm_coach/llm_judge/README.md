# Judge обязательных правил

`InvariantJudge` получает снимок активных правил, условие задачи, этап,
профиль и проверяемый запрос/ответ. Он вызывается отдельно от основной модели
через DeepSeek Pro и обязан вернуть JSON-оценку каждого ID ровно один раз.
Формат и полнота списка проверяются Pydantic; неполный или испорченный ответ
не трактуется как разрешение. В логах сохраняются только технические признаки
ошибки, без текста запроса и без ключа.

Пример: правило «Решение только на Python» и просьба «Напиши на JavaScript»
дают `conflict` до основного вызова. Если просьба допустима, но сама модель
вернула JavaScript-код, проверка `output` отклонит её ответ. Если пользователь
заменит корректный код на JavaScript в форме подтверждения, `artifact` не даст
перейти к следующему этапу.

Вердикт judge не меняет состояние задачи. Переходы остаются в workflow.
