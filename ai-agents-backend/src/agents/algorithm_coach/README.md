# Алгоритмический наставник

Самостоятельный агент Дня 11, не подкласс DialogueAgent. Его фабрика получает
порты LLM, истории, памяти, каталога моделей и учёта расхода.

- `agent.py` — два явных действия: ответ и предложения памяти. Читает snapshot,
  применяет политики, сохраняет вопрос, вызывает LLM, проверяет и сохраняет ответ.
- `input_policy.py` — непустое сообщение.
- `output_policy.py` — завершённый непустой ответ; строгая схема предложений.
- `context_policy.py` — рабочие данные + активные долговременные записи + хвост N.
- `memory_policy.py` — разрешённые поля рабочей памяти, валидация ProblemSpec.
- `models.py` — предметные Pydantic-модели, не DTO HTTP-провайдера.
- `prompts/` — отдельные промпты для обычного ответа и предложений сохранения.

Агент не меняет память автоматически. Пользователь выбирает слой и подтверждает
запись через отдельный memory API. Общие механизмы находятся в
`capabilities/memory_layers`, SQL — в infrastructure.
Полный сценарий: [руководство Дня 11](../../../docs/day11-guide.md).

## День 12: персонализация

При создании задачи выбирается профиль, неизменяемо привязанный к ней.
`context_policy.py` добавляет его актуальные предпочтения перед рабочей памятью.
Настройки — данные, а не новый системный промпт. Текущая явная просьба о стиле
важнее предпочтений; ограничения задачи и правила агента остаются выше них.
Предложения памяти также получают профиль, но не имеют права менять его.
Общий контракт: `capabilities/personalization`; хранение: `sqlite_profiles.py`.
Снимок каждого вызова сохраняет использованную версию независимо от будущих правок.
[Подробности и сравнение ответов](../../../docs/day12-guide.md).

## День 13: автомат задачи

`workflow_policy.py` — граф событий, ожидаемые действия, схемы плана, решения
и отчёта. Общий модуль `capabilities/task_workflow` подключается по композиции.
Агент резервирует команду, вызывает LLM вне транзакции, затем атомарно сохраняет
ответ и метрики при совпадении версий памяти, профиля и состояния задачи.
Пауза имеет независимый API; устаревший ответ не применяется.
Артефакты сохраняются явно, код не исполняется. Последние версии и текущий шаг
добавляются в рабочий блок context_policy и снимок каждого run.
[Граф, сценарий и ограничения](../../../docs/day13-guide.md).
