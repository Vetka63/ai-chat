# Алгоритмический наставник

Самостоятельный агент Дня 11, не подкласс DialogueAgent. Его фабрика получает
порты LLM, истории, памяти, каталога моделей и учёта расхода.

- `agent.py` — два явных действия: ответ и предложения памяти. Читает snapshot,
  применяет политики, сохраняет вопрос, вызывает LLM, проверяет и сохраняет ответ.
- `input_policy.py` — непустое сообщение.
- `output_policy.py` — завершённый непустой ответ; строгая схема предложений.
- `context_policy.py` — рабочие данные + активные долговременные записи + хвост N.
- `memory_policy.py` — разрешённые поля рабочей памяти, валидация ProblemSpec.
- `models.py` — предметные Pydantic-модели, не DTO HTTP-провайдера.
- `prompts/` — отдельные промпты для обычного ответа и предложений сохранения.

Агент не меняет память автоматически. Пользователь выбирает слой и подтверждает
запись через отдельный memory API. Общие механизмы находятся в
`capabilities/memory_layers`, SQL — в infrastructure.
Полный сценарий: [руководство Дня 11](../../../docs/day11-guide.md).
