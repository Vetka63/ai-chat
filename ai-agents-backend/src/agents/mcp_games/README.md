# Игровой MCP-агент

`McpGamesAgent` инкапсулирует чат Дня 17: при создании задаёт начальный набор
доступных MCP-серверов, а на каждом ходе принимает независимый выбор из UI.
Пустой набор отключает инструменты для этого хода. Агент сохраняет вопрос
вместе с выбранными ID, обнаруживает инструменты, передаёт
их модели, проверяет её `tool_calls` по разрешённому списку, выполняет MCP,
сохраняет результат и запрашивает итоговый ответ модели. Системная инструкция
лежит в `prompts.py`; публичный HTTP-роутинг остаётся в `application/main.py`.

Для расширения на другие инструменты не нужно копировать агента: добавьте
разрешённый сервер в каталог `capabilities/mcp_discovery/service.py` и его
специализированный MCP-адаптер. Агент работает с объявлениями инструментов
и нормализованными результатами, а не с конкретным HTTP API игр.
