# Агент игровых сводок · День 18-v2

GameDigestAgent — отдельная сущность и тип чата game_digest. Обычный
пользовательский ввод для этого чата отключён: агент работает по подписке.

1. Через API/UI создаётся чат и подписка на 30 минут. Агент проверяет
   принадлежность чата и вызывает create_watch в Python Feed MCP.
2. Отдельный процесс scheduler.py каждые 5 секунд спрашивает claim_due
   о наступивших запусках и будит агента. Это частота *опроса расписания*,
   а не частота выпуска сводки.
3. Агент получает курсор last_game_id и вызывает Java MCP инструмент
   get_new_games. Java MCP читает SQL-базу mock-games-server и возвращает
   максимум десять самых новых игр с ID больше курсора.
4. Агент проверяет ответ, формирует текст только из данных инструмента и
   вызывает save_digest в Feed MCP. Курсор продвигается после успешной
   записи. При ошибке запуск возвращается в очередь.
5. UI запрашивает list_reports и показывает три последних выпуска; каждый
   содержит максимум десять новых игр.

Полный каталог Java-сервиса не урезается до десяти записей. Если между
выпусками создано 15 игр, сводка возьмёт десять самых новых, а остальные пять
останутся в SQL-базе и будут доступны поиску. Курсор перейдёт на ID самой
новой игры.

Сводка пока детерминированная, без дополнительного вызова LLM и расходов на
токены. Адреса MCP задаются на сервере, браузер не выбирает URL инструментов.
При удалении чата удаляются подписка и отчёты; SQL-каталог не меняется.
