# Агент игровых сводок

`GameDigestAgent` — отдельная сущность и отдельный тип чата `game_digest`.
Он не ведёт обычную LLM-переписку: расписание и отчёты — его результат.
`GameFeedGateway` вызывает только разрешённые MCP-инструменты по адресу из
переменной `PY_AGENT_GAME_FEED_MCP_URL`. URL и имя инструмента не приходят из UI.

HTTP-маршруты находятся в `application/routes/game_digest.py`:
`PUT/GET/DELETE .../schedule` и `GET .../reports`. Перед любым вызовом агент
проверяет существование чата в `ConversationStore`; при удалении чата удаляет
подписку и её отчёты. Хранение игр и расписаний не дублируется в бэкенде: этим владеет
отдельный MCP-проект `python-mcp-game-feed`.

Расширение источников игр не меняет агент: он знает только MCP-контракт.
