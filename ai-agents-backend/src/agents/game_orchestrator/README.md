# Агент MCP-оркестрации

`GameOrchestratorAgent` владеет многошаговым циклом: получить ответ модели
с возможным tool call, проверить разрешённый инструмент, выполнить его,
сохранить результат и снова спросить модель. Он не реализует Java-, Python-
или Go-MCP серверы. Подробный алгоритм, хранилища и сценарий проверки —
в [руководстве дня 20](../../../docs/day20-guide.md).

`prompts.py` задаёт базовые правила модели. `agent.py` проверяет права,
аргументы, принадлежность артефактов чату, сохраняет MCP-события и расход
каждого LLM-вызова. Подключённые MCP-серверы определяют, какие инструменты
модель вообще видит. Артефакты хранятся отдельно от истории сообщений.
