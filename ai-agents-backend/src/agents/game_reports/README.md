# Агент композиции MCP-инструментов · День 19-v2

GameReportsAgent имеет отдельные чаты и системный промпт. Агент допускает
только сервер game-reports, URL которого задаётся на бэкенде, а не браузером.
McpToolChatAgent выполняет общий цикл вызова MCP и сохраняет отдельное
событие mcp_tool_events для каждого инструмента.

При обычном вопросе об играх MCP не предлагается модели. При явной просьбе
создать/сохранить отчёт модель видит только первый инструмент search_games
и обязана выбрать его. Затем **агент**, получив структурированный результат
поиска, проверяет его и формирует вызов summarize_games. После обработки
агент проверяет SummaryResult и формирует save_report с безопасным UUID.
Порядок фиксирован: search → summarize → save; максимум три tools/call.
Один MCP-сервер содержит все три инструмента.

После успешного сохранения агент передаёт результаты LLM для краткого ответа.
В истории чата видны три независимые карточки MCP со входом и результатом,
а у save_report — скачивание Markdown. Если MCP отключён, просьба сохранить
получает честный ответ политики без LLM и без файла. При ошибке этапа
последующие инструменты не вызываются.
