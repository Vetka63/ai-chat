# Общее ядро агентов

Здесь находятся только стабильные контракты, которые нужны каждому агенту:
`Agent`, `LlmClient`, строгие команды и результаты, `ConversationStore`, а также
`AgentRegistry`.

Системные промпты, валидаторы и политики поведения сюда не выносятся. Они
принадлежат конкретному агенту в `src/agents/<agent_id>`. Благодаря этому новый
агент можно развивать или позднее вынести в отдельный REST-сервис, не меняя
правила остальных агентов.

В День 7 сюда добавлен только порт `ConversationStore`. Его реализация на SQLite
находится в инфраструктуре, а решение о том, какие сообщения отправлять модели,
остаётся у `ContextPolicy` конкретного агента.
