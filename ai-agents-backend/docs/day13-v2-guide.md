# День 13 v2: проверка на Two Sum

1. Откройте клиент, выберите «Алгоритмический наставник» и создайте чат с
   условием Two Sum: вернуть индексы разных чисел с суммой `target`, иначе `[]`.
2. Убедитесь, что над чатом показано «Планирование». Попросите план со словарём
   за `O(n)`. Под ответом появится редактируемый список шагов. Обсудите план
   ещё одним сообщением, затем нажмите «Принять план и перейти к реализации».
3. Убедитесь, что отображается «Реализация» и выбран первый шаг. Выберите
   другой шаг. Попросите написать код `two_sum`. Под ответом поправьте текст,
   если требуется, и нажмите «Сохранить решение и перейти к проверке».
4. На этапе «Проверка» попросите разобрать `[2,7,11,15] / 9`, `[3,3] / 6`,
   отсутствие пары и пустой список. Примите отчёт с источником
   «Анализ LLM — код не запускался». Проверьте этап «Завершено» и три результата.
5. Повторите с новым чатом и поставьте паузу отдельно на планировании,
   реализации и проверке. После каждого перезапуска backend откройте тот же
   чат: фаза, шаг и результаты должны сохраниться. Нажмите «Продолжить» и
   попросите агента напомнить, где остановились.

Перезапуск локального backend:

```powershell
docker compose -p ai-chat-day-13-v2 restart agents-backend
```

Запуск этого варианта (используйте отдельный compose project и том):

```powershell
docker compose -p ai-chat-day-13-v2 up -d --build agents-backend agents-client
```

Клиент: http://localhost:8083, health: http://localhost:8082/health (`day=13`).
В этой версии качество решения оценивается моделью, код не исполняется.
