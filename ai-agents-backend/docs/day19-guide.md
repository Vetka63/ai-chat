# День 19-v2: композиция трёх MCP-инструментов

## Алгоритм

Один MCP-сервер python-mcp-game-reports объявляет search_games,
summarize_games и save_report. Агент получает список через tools/list.
По явной просьбе о сохранении отчёта модель выбирает search_games;
далее агент последовательно выполняет три отдельных tools/call:

1. search_games получает игры из Java SQL mock-сервиса;
2. агент передаёт точный SearchResult в summarize_games;
3. агент передаёт точный SummaryResult в save_report.

Агент проверяет данные и порядок до следующего шага. Файл не создаётся,
если поиск или обработка вернули ошибку. В финальном ответе LLM используется
результат сохранения. Для каждого вызова сохраняется отдельный след в чате.
День 18-v2 продолжает работать независимо и использует тот же код каталога
в другом Compose-проекте и собственном Docker-томе.

## Параллельный запуск для проверки

Из корня репозитория на ветке ai-challenge-day-19-v2 задайте host-порты:

    $env:PY_AGENTS_API_PORT='8182'
    $env:PY_AGENTS_UI_PORT='8183'
    $env:PY_GAMES_API_PORT='8184'
    $env:JAVA_GAMES_MCP_PORT='8185'
    $env:PY_GAMES_MCP_PORT='8186'
    $env:PY_GAME_FEED_MCP_PORT='8187'
    $env:PY_GAME_REPORT_MCP_PORT='8188'
    docker compose -p ai-chat-day-19-v2 up -d --build agents-client game-feed-worker

Проект ai-chat-day-18-v2 остаётся на 8083. Разные имена Compose дают разные
контейнеры и тома; данные между проектами не смешиваются.

## Проверка через UI

1. Откройте http://localhost:8183/. Выберите агента «Отчёты по играм» и
   создайте чат с подключённым сервером «Отчёты об играх · Python».
2. Спросите «Что такое RPG?». Должен появиться обычный ответ без MCP-карточек
   и без файла.
3. Отправьте «Создай и сохрани отчёт об играх про космос». Должны появиться
   ровно три карточки одного сервера: search_games, summarize_games,
   save_report. В раскрытых данных вход обработки совпадает с выходом поиска,
   а вход сохранения — с выходом обработки.
4. У третьей карточки скачайте Markdown. Обновите страницу: сообщения и
   все три MCP-события должны сохраниться.
5. Отключите MCP для следующего сообщения и повторите просьбу сохранить
   отчёт. Новых вызовов не будет; агент не заявит, что файл создан.
6. Убедитесь, что http://localhost:8083/ (день 18-v2) по-прежнему работает.

Автотесты: pytest в ai-agents-backend и python-mcp-game-reports, pnpm test
в ai-agents-client. Тесты подтверждают tools/list из трёх инструментов,
строгий порядок, передачу данных и отсутствие save при ошибке поиска.
