# Go MCP Report Store · День 20

Независимый HTTP MCP-сервер на Go. Инструмент `save_report` принимает готовый
отчёт из Python MCP, сохраняет Markdown в собственном томе Docker и возвращает
подтверждение с ID, именем файла и SHA-256 содержимого. Полный Markdown не
дублируется в ответе MCP: бэкенд сверяет хеш и сохраняет свою копию для UI.
Повтор с тем же UUID и тем же содержимым безопасен;
другое содержимое под тем же UUID отклоняется. Путь к файлу модель не задаёт.
