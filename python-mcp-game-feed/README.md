# Game Feed MCP · День 18-v2

Отдельный MCP-сервер для подписок и сводок, а не для хранения каталога игр.
Игры хранятся без ограничения в SQL-базе Java-сервиса mock-games-server.
Здесь SQLite содержит таблицы watches, runs, reports.

Инструменты MCP: create_watch, get_watch, cancel_watch, delete_watch,
list_reports, claim_due, release_failed, save_digest. Сервис не вызывает
Java MCP и не составляет отчёт сам: отдельный процесс будит GameDigestAgent,
а агент получает новые игры через Java MCP и сохраняет итог через этот MCP.

Подписка задаётся на 1800 секунд: первый выпуск через 30 минут, далее каждые
30 минут. claim_due атомарно резервирует наступивший запуск, save_digest
записывает отчёт и продвигает last_game_id. После сбоя release_failed
возвращает запуск в очередь. Ключ (watch_id, scheduled_for) предотвращает
повторную запись. Для подписки сохраняются три последние *сводки*; каждая
содержит не более десяти *новых игр*. Эти пределы не затрагивают Java-каталог.

База находится в постоянном томе game-feed-data и переживает обычный
перезапуск контейнера. Команда docker compose down -v удалит её — не используйте
её для проверки сохранения. Учебный вариант рассчитан на один процесс
планировщика, не на распределённую очередь.
