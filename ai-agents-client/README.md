# Клиент Python Agents — День 9

`features/context/` — настройки стратегии, просмотр summary и создание независимой
копии для сравнения. `features/tokens/` теперь учитывает вызовы purpose=summary.
Режим хранится у разговора на сервере; сводка не создаётся при просмотре или preview.

Vue 3 интерфейс показывает сохранённые диалоги выбранного Python-агента. Чаты
создаются и удаляются через backend, а при загрузке страницы клиент получает
список и сообщения из SQLite. В браузере хранится только идентификатор последнего
выбранного чата, но не сама история.

```powershell
cd ai-agents-client
pnpm install
pnpm dev
```

Откройте <http://localhost:5174>. Production-сборка: `pnpm build`, тесты:
`pnpm test`.

День 8: `features/tokens/` содержит метрики запусков, оценку контекста и экспорт MD.
`useAgentChat` отправляет только новый текст и ID модели, а историю и usage получает с сервера.
Preview черновика обновляется с задержкой 500 мс и отменой устаревших запросов.
Компоненты не вычисляют тарификацию: используют сохранённую серверную оценку стоимости.

## Компоновка интерфейса

- `components/ChatSidebar.vue` — левая колонка: создание, выбор и удаление чатов
  текущего агента. Список прокручивается независимо от переписки и настроек.
- `components/MessageComposer.vue` — поле ввода; слот нижней строки содержит
  `ModelPicker.vue`. Выбор модели относится к следующему ответу и не очищает историю.
  Меню поддерживает стрелки, Home/End, Escape и закрытие при клике снаружи.
- `components/AgentSidebar.vue` — правая панель: агент, свёрнутый список тем
  и слот подключаемых настроек. Сейчас это `ContextPanel` и `TokenPanel`.
- `App.vue` связывает компоненты с `useAgentChat`, управляет темой и видимостью
  панелей. Закрытие настроек не уничтожает их компоненты и введённые значения.
- `style.css` — общие цвета тем и адаптивная сетка. До 1180 px настройки становятся
  выдвижной панелью, до 760 px так же работает список чатов. Escape закрывает
  панель и возвращает фокус; на телефоне одновременно открыта только одна панель.

Связь с API, память, сжатие и подсчёт токенов остаются в прежних модулях;
компоненты компоновки не содержат бизнес-логику агента.
