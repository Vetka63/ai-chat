# Клиент Python Agents — День 6

Отдельный Vue 3 интерфейс для новых Python-агентов. Старый `ai-chat-client` не
изменяется и продолжает работать с Java backend.

Клиент получает список агентов из `GET /api/v1/agents`, отправляет только текущее
поле `message` в выбранный агент и показывает результат. Сообщения существуют
только в памяти вкладки: «Новый чат» или обновление страницы их очищает. Это
намеренно — постоянная история относится к Дню 7.

```powershell
cd ai-agents-client
pnpm install
pnpm dev
```

Откройте <http://localhost:5174>. Для production-сборки используйте `pnpm build`,
для тестов — `pnpm test`.
