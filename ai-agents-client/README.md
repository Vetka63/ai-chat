# Клиент Python Agents — День 15

Панель задачи показывает утверждённые версии и причины заблокированных переходов.
Доработка требует замечаний и шага плана, отчёт — явной проверки списка блокеров.
API повторно проверяет все условия независимо от UI.
[Полный цикл и сценарий сдачи](../ai-agents-backend/docs/day15-guide.md).

`features/invariants/` — явный редактор обязательных правил и журнал вердиктов.
Кнопка примера заполняет только черновик; сохранение возвращает задачу к planning.
Показываются причины конфликтов, неопределённость и отдельный расход judge.
Старые артефакты помечены как неактуальные при изменении версии правил.
[Сценарий Дня 14](../ai-agents-backend/docs/day14-guide.md).

`features/tasks/` — отдельная панель этапов, шага плана, паузы, артефактов и журнала.
Пауза доступна во время вызова модели. Чат заблокирован на паузе/после завершения;
переходы проверяются сервером. MD-отчёт включает автомат и историю его изменений.
[Сценарий Дня 13](../ai-agents-backend/docs/day13-guide.md).

`features/profiles/` — выбор профиля при создании задачи, редактор предпочтений
и сохранение с проверкой версии. Профиль задачи неизменяем, настройки самого
профиля можно редактировать для следующих запросов. В отчёте сохранены снимки
профиля каждого вызова. [Сценарий Дня 12](../ai-agents-backend/docs/day12-guide.md).

`features/memory/` — отдельная панель трёх слоёв для алгоритмического наставника:
карточка, ручные записи, подтверждение предложений и включение заметок.
Новая задача создаётся с условием и размером хвоста N. MD-отчёт Дня 11 включает
память, её источники, снимки вызовов и расход токенов.
Настройки диалогового агента Дня 10 сохранены.

`features/context/` — выбор Sliding Window, Sticky Facts, Branching, а также режимов
full/summary при создании чата. После создания панель показывает неизменяемую
конфигурацию, окно, key-value facts, checkpoint и семейство веток.
`features/tokens/` различает расходы purpose=dialogue/summary/facts и экспортирует
настройки Дня 10 в Markdown. Режим хранится у разговора на сервере; preview не
создаёт summary/facts и не вызывает LLM.

Vue 3 интерфейс показывает сохранённые диалоги выбранного Python-агента. Чаты
создаются и удаляются через backend, а при загрузке страницы клиент получает
список и сообщения из SQLite. В браузере хранится только идентификатор последнего
выбранного чата, но не сама история.

```powershell
cd ai-agents-client
pnpm install
pnpm dev
```

Откройте <http://localhost:5174>. Production-сборка: `pnpm build`, тесты:
`pnpm test`.

День 8: `features/tokens/` содержит метрики запусков, оценку контекста и экспорт MD.
`useAgentChat` отправляет только новый текст и ID модели, а историю и usage получает с сервера.
Preview черновика обновляется с задержкой 500 мс и отменой устаревших запросов.
Компоненты не вычисляют тарификацию: используют сохранённую серверную оценку стоимости.

## Компоновка интерфейса

- `components/ChatSidebar.vue` — левая колонка: создание, выбор и удаление чатов
  текущего агента. Дочерние ветки показаны под родителем; список прокручивается
  независимо от переписки и настроек.
- `components/NewChatDialog.vue` — обязательная настройка названия и стратегии
  до создания чата. Пока чат не создан, отправка сообщений недоступна.
- `components/MessageComposer.vue` — поле ввода; слот нижней строки содержит
  `ModelPicker.vue`. Выбор модели относится к следующему ответу и не очищает историю.
  Меню поддерживает стрелки, Home/End, Escape и закрытие при клике снаружи.
- `components/AgentSidebar.vue` — правая панель: агент, свёрнутый список тем
  и слот подключаемых настроек. Сейчас это `ContextPanel` и `TokenPanel`.
- `App.vue` связывает компоненты с `useAgentChat`, управляет темой и видимостью
  панелей. Закрытие настроек не уничтожает их компоненты и введённые значения.
- `style.css` — общие цвета тем и адаптивная сетка. До 1180 px настройки становятся
  выдвижной панелью, до 760 px так же работает список чатов. Escape закрывает
  панель и возвращает фокус; на телефоне одновременно открыта только одна панель.

Связь с API, память, сжатие и подсчёт токенов остаются в прежних модулях;
компоненты компоновки не содержат бизнес-логику агента.

`components/OutputSettings.vue` — ручной лимит основного ответа: переключатель,
ползунок и точное числовое поле. По умолчанию `null` (выбирает провайдер), при
включении — 1200. `useAgentChat` передаёт одинаковый `max_output_tokens` в preview
и run; сервер сохраняет его при отправке, поэтому переключение чатов и перезапуск
восстанавливают настройки каждого диалога. Для нового чата лимит выключен.
Сводка памяти не наследует ползунок; её фиксированный лимит также снят.
