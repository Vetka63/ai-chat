# Панель памяти Дня 11

- `api.js`: команды серверному memory API.
- `useMemoryLayers.js`: актуальный workspace, версии для записи, блокировка
  параллельных действий, отбрасывание устаревших ответов при смене чата.
- `MemoryPanel.vue`: три слоя, карточка задачи, ручные записи, подтверждение
  и отклонение предложений, источник данных, снимок последнего основного вызова.
- `memory.test.js`: создание задачи, явное сохранение, гонка загрузок,
  подтверждение и учёт служебного API-вызова.

Данные не сохраняются в localStorage; источником истины остаётся backend.
Панель подключается по capability `memory_layers`, старый ContextPanel остаётся
у диалогового агента. Экспорт Дня 11 находится в `features/tokens/report.js`.
