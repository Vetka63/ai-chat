# Панель обязательных правил

`InvariantPanel.vue` редактирует черновик и показывает сохранённые правила и
последние 50 проверок. Только кнопка сохранения отправляет изменения.
`useInvariants.js` добавляет ID команды и ожидаемую версию workflow, обновляет
память после успеха/конфликта. `api.js` не знает о ключах провайдера.

При смене задачи/версии правил черновик загружается заново; фоновое обновление
аудита его не стирает. Завершённая задача не редактируется. На паузе менять правила
можно: backend сохранит паузу и вернёт фазу в planning.

Policy-refusal показан в баннере и постоянном журнале проверок, а не как выдуманный
ответ LLM. Расход judge находится в tokens; MD-отчёт включает правила и аудит.
