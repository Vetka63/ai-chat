# Панель обязательных правил

`useInvariants.js` загружает отдельный от чата набор правил и результаты
проверок; `InvariantPanel.vue` показывает компактную строку и раскрываемый
редактор. У каждого чата свои правила. После сохранения обновляется workflow,
так как старый кандидат результата становится неактуальным.

Редактор доступен только на активном этапе планирования. Во время паузы и
после принятия плана правила видны, но заблокированы для изменения. Последние
проверки показывают `pass`, `conflict` или `uncertain` и краткие причины.
