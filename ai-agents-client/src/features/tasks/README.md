# Панель задачи

`TaskPanel.vue` показывает фазу, паузу, текущий шаг плана, ожидаемое действие,
историю артефактов и журнал. План задаётся строками, решение — текстом,
отчёт — текстом с обязательным указанием источника проверки и списка блокеров.
Пустой список разрешён только после явного подтверждения, что пользователь его проверил.

`useTaskWorkflow.js` отправляет явные версионированные команды через `api.js`,
перечитывает серверное состояние и блокирует чат на паузе/после done.
Пауза имеет отдельную кнопку, которая остаётся доступной во время LLM-вызова.
Результат refresh защищён от смены чата. Ошибка не стирает черновик артефакта.
При смене задачи или фазы черновик сбрасывается, чтобы не перенести его в чужой чат.

Состояние приходит в memory workspace, но его модель и транзакции находятся
в отдельном backend-модуле task_workflow. UI не вычисляет разрешённые переходы:
получает allowed_events и blocked_events с причинами с сервера. API всё равно
самостоятельно проверяет их. Утверждение, передача решения и принятие отчёта
отправляют точный ID показанной версии. Доработка отправляет замечания и ID шага.

Новая версия плана через форму получает новые ID шагов. API поддерживает
сохранение прежних ID текущего плана, если необходим редактор отдельных шагов.
С Дня 14 сохранение артефакта вызывает judge после локальной проверки; с Дня 15
обязательное правило этапа действует даже без пользовательских инвариантов.
Анализ LLM не обозначается запуском тестов. Старые версии видны в истории, но
версии прежнего цикла/условия/правил или до Дня 15 нельзя утвердить как актуальные.
`tasks.test.js` и `day15.test.js` проверяют кнопки, команды, блокировки, формы и MD.
