# Раздел MCP · День 16

`McpExplorer.vue` — самостоятельная рабочая область, открываемая кнопкой MCP в
левой колонке. Это не чат и не настройка агента. `api.js` содержит только два
HTTP-вызова: загрузку разрешённых серверов и проверку соединения.

После нажатия кнопки подключения UI показывает имя сервера, согласованную
версию протокола, список tools и их входные JSON Schema. Каждое нажатие создаёт
новое краткоживущее соединение; UI не показывает его как постоянно активное.
Ошибки видны отдельно от результата и не оставляют прежний список как будто
это новый успешный ответ.

Настройки сервера, команды запуска и ключи в браузере не хранятся. Проверка
раздела — `McpExplorer.test.js` и тест переключения в `App.test.js`.
