# Интерфейс задачи — день 13 v2

`useWorkflow.js` загружает состояние выбранного чата и обновляет его после
ответа модели или команды. `WorkflowPanel.vue` показывает фазу, следующее
действие, паузу, выбранный шаг, подтверждённые результаты и журнал.

Последний ответ модели подставляется в редактируемое предложение текущего
этапа. Для плана извлекается нумерованный список из раздела «Шаги»;
пользователь видит и исправляет его до сохранения. Неудачное извлечение
оставляет исходный текст доступным для ручной правки, переход не происходит.
Подтверждение отправляет команду с версией состояния, и UI отображает новую
фазу только после ответа backend. Во время паузы и после завершения ввод
сообщений отключён.
