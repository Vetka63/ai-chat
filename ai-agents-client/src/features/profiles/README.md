# Профили пользователя

- `api.js` — серверные операции списка, создания и обновления.
- `options.js` — подписи и допустимые значения предпочтений, нейтральные defaults.
- `useProfiles.js` — загрузка только для агента с capability personalization,
  состояние сохранения и обновление привязанной памяти без запроса к LLM.
- `ProfilePanel.vue` — явная форма, создание профиля, редактирование с ожидаемой версией.
- `profiles.test.js` — создание задачи, формы, конфликты, отчёты и совместимость.

`NewChatDialog` выбирает профиль при создании задачи. Выбор в редакторе меняет
редактируемый профиль, а не привязку открытого чата — интерфейс предупреждает об этом.
Конфликт сохранения не стирает черновик. Явное обновление перечитывает серверные данные.
Настройки хранятся в SQLite, не в localStorage. Удаление и перепривязка не реализованы.
Новый профиль становится выбором по умолчанию для следующей задачи.
