# День 27 — фактическая проверка 6 октября 2026

## Что проверено

Kotlin / Spring Boot backend, Vue-клиент, локальная Ollama 0.35.1, Qwen3 8B Q4_K_M. Запросы выполнялись через `http://localhost:8483/api/v1` — тот же Nginx и API, которыми пользуется интерфейс. Облачные модели не вызывались. Серверная SQLite содержит отдельные `chats` и `messages`; исходные `runs` дня 26 сохранены.

Во втором ответе модель предложила туристический маршрут. Географические факты и цены не верифицировались: это тест передачи контекста, не проверка туристического справочника. Для воспроизведения в гайде предложен более нейтральный вопрос о подготовке поездки. Статус COMPLETED не является оценкой истинности ответа.

## Сбои, повторы и переполнение

Для проверок создан отдельный временный чат, не использовались пользовательские диалоги.

1. Ollama остановлена. Сообщение сохранено как USER/FAILED; ASSISTANT не выдуман.
2. Повтор POST с тем же requestId вернул ту же USER-запись и одну реплику; модель не вызывалась заново.
3. Ollama запущена. Явный `/retry` сохранил прежний ID USER, добавил ровно один ASSISTANT с ответом `4`; всего две реплики.
4. Запрос с 14999 UTF-16-символами превысил окно: Ollama вернула HTTP 400, **15161 токен при окне 8192**. Это ответ runtime, не приблизительный подсчёт приложения. USER остался в БД, история не была урезана. На финальной сборке ошибка отображается обычным русским текстом, без вложенного JSON.
5. После этого новый короткий вопрос получил ответ `13`. Неуспешный большой USER остался в истории, но не вошёл в контекст следующего хода.
6. Одновременно с действующей генерацией второй чат-запрос и запрос `/runs` получили **409**; первый продолжал работать и завершился HTTP 200. Для этого запросы были отправлены параллельно, а факт RUNNING проверен чтением чата. Первый последовательный диагностический замер не доказывал перекрытие во времени и был заменён этим тестом.
7. Повтор завершённого запроса не изменил число сообщений или ID сохранённого ASSISTANT.
8. Только временный технический чат удалён через DELETE: 204, последующее чтение — 404. Два демонстрационных чата и исходные результаты дня 26 остались.

Один обычный лабораторный запуск также был сохранён при последовательной диагностике; он не удалялся. Исходные три результата дня 26 доступны по прежним ID.

## Автотесты и границы уверенности

- **21 backend-тест**: сохранение, восстановление, порядок messages, изоляция, requestId, retry, общий gate, удаление, частичный вывод, ошибки runtime, отсутствие cloud fallback и неявного лимита выхода.
- **15 frontend-тестов**: чат, новый запрос без клиентской history, сохранённые результаты, ошибка, подтверждение удаления, безопасный текст модели, автоскролл, настройки, двойная отправка, потеря HTTP-ответа и переключение разделов.
- TypeScript и production-сборки backend/client прошли.
- Живой браузерный сценарий автоматически **не пройден**: инструмент браузера не запустил сеанс из-за `failed to write kernel assets`; сброс и повтор подключения не помогли. Не выдаём HTTP-проверки и компонентные тесты за визуальную проверку настоящего браузера.
