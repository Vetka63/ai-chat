# День 28: проверка и видео

## Что показываем

Новый корпус русских рассказов Warhammer, локальные embeddings/retrieval, локальную Qwen3 и необязательное сравнение с DeepSeek на одном найденном контексте. Это отдельный раздел уже существующего приложения локальной недели. Pro Git не изменён; замена корпуса согласована пользователем, но отличается от буквальной фразы задания «индекс прошлой недели».

## Запуск

PowerShell, папка `F:\ai-advent-challenge\ai-chat\local-llm`:

```powershell
docker compose -f compose.yml -f compose.gpu.yml up -d ollama
docker compose exec ollama ollama pull qwen3:8b
docker compose exec ollama ollama pull qwen3-embedding:0.6b
# Только локально, облако по умолчанию отключено.
docker compose -f compose.yml -f compose.gpu.yml up -d --build backend client
```

Для сравнения используйте существующий секретный `.env` корня и явный флаг:

```powershell
$env:RAG_CLOUD_ENABLED = 'true'
docker compose --env-file ../.env -f compose.yml -f compose.gpu.yml up -d --build backend client
```

Не демонстрируйте содержимое `.env` на видео. Ключ не вводится в UI. Порты: UI 8483, backend 8482, Ollama 11436.

## Подготовка корпуса, если БД пустая

1. Откройте http://localhost:8483/#rag. Справа раскройте «Корпус и индексация» → «Добавить UTF-8 TXT».
2. Выберите предоставленный файл и понятное название. Для этих шести файлов начальные заголовки: КРАКЕН; МОЛНИЕНОСНЫЙ РЕЙС; НЕКСУС; ИСКУПИТЕЛЬ; СУМРАЧНЫЕ ЧАСЫ; ИСПЫТАНИЕ ВЕРЫ. Это исключит рекламу других книг перед рассказом.
3. Нажмите «Загрузить» для каждого файла. Исходные файлы не меняются; тексты сохраняются только локально.
4. Нажмите «Построить новый индекс», дождитесь READY. По умолчанию 1400 символов / overlap 180. Если индекс уже READY, повторять построение не нужно.

Импорт всех шести файлов можно выполнить скриптом `scripts/import-day28.ps1 -Paths @(<абсолютные пути>) -BuildIndex`. Реальные пути книги не зашиты в репозиторий.

## Сценарий записи — без устных объяснений

1. Откройте раздел «День 28 · RAG». Покажите список шести документов и READY индекс справа. Выберите все рассказы, Top-K 5, threshold 0.35, бюджет 7000, temperature 0, reasoning выключен, cap пустой.
2. Выберите режим **«Локальная LLM»** и Qwen3. Спросите: «Что Квара носил на своей броне в рассказе „Кракен“ и сколько было имён?».
3. Дождитесь карточки. Ожидание: восемь имён на броне. Источники раскройте ниже; найдите фрагмент с восемью именами. Проверьте реальный текст, не только VALID.
4. Покажите input/output, latency и загрузку модели. Это реальные числа runtime. COMPLETED означает завершение генерации, не оценку истины.
5. Переключите режим на **«Сравнить параллельно»**, облачная модель `deepseek-v4-pro` или Flash, задайте тот же вопрос. Поиск выполнится один раз. Одна карточка может завершиться раньше другой.
6. Прокрутите к двум карточкам и раскройте «Диагностика одинакового контекста»: видны общий prompt hash, кандидаты, ранги и именно переданные sources.
7. Выполните ещё два вопроса: «Кто такая Сальватория Грант и каким самолётом она управляла в „Молниеносном рейсе“?»; «Почему город Термина поёт, по объяснению Северина Рейн в „Сумрачных часах“?». Ожидания: пилот „Валькирии“; ветер в шахтах/туннелях.
8. Повторите один вопрос новым запросом. Сравните смысл ответов, завершение и время. Первый холодный запуск учитывает загрузку весов; его не выдаём за warmed latency. Разные модели имеют разные токенизаторы.
9. Сохраните «Ваш вывод: качество, скорость, стабильность». Например, отметьте, какие факты подтверждены, время и различия формулировок. Нажмите «Скачать MD».
10. Перезагрузите страницу и откройте результат слева: чтение истории не вызывает LLM.

## Полностью локальное доказательство

После загрузки обеих моделей и завершения активных запросов:

```powershell
docker compose -f compose.yml -f compose.gpu.yml -f compose.offline.yml up -d
```

Backend и Ollama подключены только к internal-сети, DeepSeek отключён, ключ пустой. Nginx имеет также обычную сеть для публикации UI на Windows и проксирует запросы к backend по внутренней сети; это не внешний LLM-прокси. Используйте UI 8483 и его `/api/v1/...`: прямой backend-порт 8482 в этом профиле на Windows может быть недоступен. В UI облачные варианты недоступны. Повторите вопрос в LOCAL: и поиск, и ответ должны работать. Вернуть сравнение — запуск обычного compose с `RAG_CLOUD_ENABLED=true` и секретным `.env`, как выше. Не переключайте deployment во время генерации.

## Полная контрольная серия

`evaluation/day28-cases.json` содержит 10 вопросов/ожиданий. Они не входят в индекс.

```powershell
.\scripts\verify-day28.ps1 -Repeats 3 -Mode COMPARE -CloudModel deepseek-v4-pro
```

Это 30 экспериментов / до 60 генераций, включая 30 облачных; требует баланса. Каждый обычный запуск создаёт новую ignored папку `artifacts/day28-<дата-время>`, а эксперименты также видны в UI после обновления. Для возобновления явно передайте прежнюю `-OutputDirectory`: сохранённые результаты не генерируются заново. После изменения кода или параметров используйте новую папку. `-StopOnFailure` остановит серию при runtime-ошибке/перезапуске, сохранив receipts. `expectedWordsMatched` — только поиск ожидаемых слов, не доказательство смысловой правильности. Полный вывод требует просмотра ответов и sources.
