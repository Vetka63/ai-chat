## 1. Запуск

Если http://localhost:8483 уже работает, пропустите запуск. Иначе включите Docker Desktop:

```powershell
cd F:\ai-advent-challenge\ai-chat\local-llm
./scripts/start-day28.ps1 -Cloud
```

`-Build` добавляйте после изменения кода. Без `-Cloud` новые ответы только локальные.
Для полностью изолированного запуска после скачивания моделей: `./scripts/start-day28.ps1 -Offline`.
Не показывайте `.env`, ключи или полный environment контейнера на видео. История/индекс хранятся
в volume и не удаляются обычным stop/restart. Скрипт проверяет минимум 20GiB на диске данных Docker.

Откройте [лабораторию](http://localhost:8483/#rag). Справа должны быть:
READY ·403 чанков ·a15a954a, шесть рассказов и локальная `qwen3:8b`.
Слева — сохранённые вопросы с датой/коротким UUID, в центре — вопрос и ответы.
Панель настроек относится к **новому запросу**; параметры сохранённого — в раскрываемом блоке под ответами.

   Оба ответа должны сообщать **восемь имён**. DeepSeek дополнительно уточняет четыре справа/слева.
4. Покажите время, input/output, локальные load time и tokens/s. Первый локальный вызов может быть холодным.

7. Раскройте «Сохранённые параметры эксперимента»: COMPARE, topK = 5, threshold = 0.35,

8. Покажите «Ваш вывод» и нажмите «Скачать MD». Экспорт не вызывает модели заново.

## 3. Полностью локальная часть

Уже сохранено [offline-доказательство](http://localhost:8483/#rag/9e9be1c4-1e7b-4ae2-88b7-3516ae579471), **9e9be1c4**:
новый вопрос, embedding без cache hit, только Qwen и правильные восемь имён/расположение.
Этот первый запуск был холодным и медленным; не выдавайте его за прогретую скорость.

Для **живой** демонстрации отсутствия облака:

1. Дождитесь окончания всех запросов/индексации. В PowerShell:

```powershell
./scripts/start-day28.ps1 -Offline
```

2. Обновите UI8483. DeepSeek/COMPARE недоступны, подпись сообщает про отключённое облако.
3. Нажмите «＋ Новый вопрос», выберите LOCAL. Настройки: topK = 5, threshold = 0.35,
   budget7000, temperature = 0, Reasoning выключен, cap пустой.
4. Введите: **«В рассказе „Кракен“ сколько имён было на броне Квары и где они были расположены?»**.
5. Дождитесь ответа. Ожидание: восемь, по четыре справа/слева, со ссылкой на источник.
6. Покажите единственную локальную карточку, источник и объяснение offline в выводе.
   После простоя/смены контейнеров загрузка модели может занять десятки секунд; не нажимайте повтор во время выполнения.
7. При необходимости задайте новый перефразированный вопрос, чтобы видеть «embedding вычислен локально»:
   точное повторение может использовать локальный кеш query-вектора. Ответы при этом генерируются заново.
8. Вернуть обычный режим для сравнения:

```powershell
./scripts/start-day28.ps1 -Cloud
```

Сохранённые ответы останутся. Само наличие старой облачной карточки в истории не означает новый cloud-вызов.
Offline backend/Ollama имеют только internal-сеть, key пуст, внешний DNS-запрос из backend не проходит.
Nginx остаётся локальным входом для браузера. API в offline используйте через 8483, не прямой 8482.

## 5. Свой новый вопрос и гибкий выбор LLM

1. Нажмите «＋ Новый вопрос».
2. Выберите **Локальная LLM**, **DeepSeek** или **Сравнить параллельно**.
3. Для cloud выберите `deepseek-v4-pro` справа. Облако требует явного `-Cloud` и ключа на backend.
4. Настройте индекс/область поиска, topK, threshold, budget и генерацию. Настройки относятся только к новому запуску.
5. Введите, например: **«Почему город Термина поёт, по объяснению Северина Рейн в „Сумрачных часах“?»**.
   Ожидание: ветер в шахтах/туннелях, не магическая причина из общего лора.
6. Нажмите кнопку отправки один раз. COMPARE показывает готовую карточку независимо от второй.
7. Сверьте источники, заполните вывод и скачайте MD.

Низкий similarity не является вероятностью правильности. Правильный ID источника тоже не доказывает
все утверждения. Сохраняйте неудачные результаты, чтобы сравнение качества было честным.
При definite HTTP-отказе запрос можно исправить; при неизвестном исходе используйте receipt того же UUID,
не создавайте случайно новый платный запрос.

## 6. Если индекс пуст на другой установке

1. Скачайте локальные модели через start-script.
2. Справа «Корпус и индексация» → «Добавить UTF-8 TXT» → файл/название/начальный заголовок.
3. Для предоставленных файлов заголовки: КРАКЕН; МОЛНИЕНОСНЫЙ РЕЙС; НЕКСУС;
   ИСКУПИТЕЛЬ; СУМРАЧНЫЕ ЧАСЫ; ИСПЫТАНИЕ ВЕРЫ. Реклама до них исключается явно.
4. Загрузите шесть файлов, нажмите «Построить новый индекс», дождитесь READY.
   Готовый 403-чанковый индекс повторно строить для смены генеративной модели не нужно.
5. Можно использовать `scripts/import-day28.ps1 -Paths @(<ваши абсолютные пути>) -BuildIndex`.
   Пути книги не зашиты в backend, тексты не входят в Git.

## 7. Полная контрольная серия

```powershell
./scripts/verify-day28.ps1 -Repeats 3 -Mode COMPARE -CloudModel deepseek-v4-pro -MaxOutputTokens 512 -StopOnFailure
```

Это 30 экспериментов/60 генераций, из них 30 платных. Готовый текущий набор уже выполнен, не нужно
повторять его для открытия результатов. Скрипт сохраняет request/result/summary в ignored artifacts.
Одна папка с теми же параметрами возобновляет receipt без нового inference; изменённые параметры,
модель или индекс требуют новой папки. Для стартовой Q4 указывайте `-LocalModel qwen3:4b-q4_K_M`.
`expectedWordsMatched` — только диагностические слова, не семантический судья.

Подробные цифры/ошибки: [day28-verification.md](day28-verification.md).
Схема: [day28-rag-overview.html](diagrams/day28-rag-overview.html).

Остановить только приложение без удаления моделей/БД:

```powershell
docker compose --env-file ../.env -f compose.yml -f compose.gpu.yml stop
```
