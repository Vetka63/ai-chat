# Контрольная точка дня 30

2026-10-11, ветка `ai-challenge-day-30` от дня 27.

## Готово

Отдельные Docker контейнеры, новый volume SQLite, локальная Qwen 8B, приватный API с паролем/HttpOnly-сессией, server-side 10 запросов/мин и один активный запрос, размер истории UTF-8 отдельно от реального окна 8192 токена, инструкции и проверенная Archify-схема. 30 backend + 21 frontend unit-тест, 25 живых PASS, отдельное доказательство native context overflow. Secret/env/data не коммитятся.

## Настроено на Windows

Пользователь создал PRIVATE-сеть и подтвердил устройства; Enable-скрипт создал точный listener IPv4:8583 → 127.0.0.1:8583 и узкое правило AIChallenge-Day30-ZeroTier. Global firewall/execution policy не менялись. PowerShell 5.1 encoding и wildcard InterfaceAlias исправлены.

## Что осталось подтвердить

Реальное открытие сайта и генерация с iPhone по Wi-Fi/сотовой сети, отключение VPN как отрицательная проверка. ПК открывает свой адрес ZeroTier с HTTP 200; телефон пока не открыл. В Nginx не обнаружены запросы iPhone. Проверяем переключатель/статус ZeroTier VPN и назначенный адрес на телефоне. `Enable Default Route` должен остаться выключенным.

Нельзя называть Day 30 полностью end-to-end проверенным, пока этого подтверждения нет. Широкий Firewall allow, публикация Ollama или отключение Firewall не требуются и не выполнялись. Дополнительный пароль: `.env.day30`, показывать его в видео/чате нельзя.
