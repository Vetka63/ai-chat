# День 27 — локальный чат: проверка и видео

## Запуск

```powershell
cd F:\ai-advent-challenge\ai-chat\local-llm
docker compose -f compose.yml -f compose.gpu.yml up -d --build
```

Модель Qwen3 8B уже установлена в отдельном volume. Если это другой компьютер, сначала выполните `docker compose -f compose.yml -f compose.gpu.yml exec ollama ollama pull qwen3:8b`.

Откройте http://localhost:8483/#chat. Раздел «День 26 · Проверки» остаётся доступным отдельно. Интерфейс дня 27 по умолчанию открывает выбранный в URL или последний чат.

## Основной сценарий в UI

1. Откройте «День 27 · Чат».
2. Нажмите «＋ Новый чат», задайте название «Проверка памяти», оставьте модель `qwen3:8b`, нажмите «Создать чат».
3. Справа установите температуру 0,3. Reasoning выключите, поле максимума токенов оставьте пустым. При узком окне настройки открываются кнопкой «Настройки» в заголовке.
4. Отправьте:

   > Меня зовут Сергей. Я планирую поездку в Казань на три дня. Бюджет — 15000 рублей. Предпочитаю пешие прогулки и не хочу посещать бары. Запомни условия и кратко подтверди их.

5. Дождитесь подтверждения. На экране должны остаться и ваш текст, и ответ модели. Первый запрос может быть дольше из-за загрузки весов.
6. Отправьте:

   > Предложи три пункта подготовки к этой поездке с учётом моих условий. Не придумывай названия достопримечательностей и цены. Ответь кратко.

7. Раскройте под вторым ответом «Токены и параметры ответа». Должны быть реальные input/output tokens, время и **3 сообщения + системная инструкция**: первый USER, первый ASSISTANT, второй USER.
8. Обновите страницу. Переписка должна остаться, новый LLM-вызов от обновления страницы не возникает.
9. Для проверки настоящего перезапуска выполните:

   ```powershell
   docker compose -f compose.yml -f compose.gpu.yml restart backend
   ```

   Дождитесь запуска backend и нажмите «Обновить» в списке чатов либо обновите страницу.

10. В том же чате отправьте:

    > Напомни: как меня зовут, куда и на сколько дней я собираюсь, какой у меня бюджет и какие предпочтения и запрет? Ответь коротким списком, используя только факты, которые я сообщил.

11. Проверьте ответ: Сергей; Казань; 3 дня; 15000 рублей; пешие прогулки; без баров. Метрики третьего ответа показывают **5 сообщений + системная инструкция**. Это подтверждает восстановление контекста без повторного объяснения.

Если ответ модели содержит фактические ошибки, это не доказательство ошибки сохранения: отдельно проверьте исходные реплики и число сообщений в контексте. Небольшая локальная модель может галлюцинировать; интеграция не превращает её в достоверный справочник.

## Изоляция диалогов

1. Создайте второй чат «Без контекста».
2. Отправьте:

   > Как меня зовут и куда я собираюсь? Используй только сообщения этого диалога. Если я ещё не сообщал эти сведения, прямо скажи, что данных нет.

3. Модель должна сообщить, что вы ещё не сообщили эти данные, а не использовать сведения первого чата.
4. Слева вернитесь в «Проверка памяти». Его сообщения должны остаться на месте.

## Локальность

```powershell
docker compose -f compose.yml -f compose.gpu.yml exec ollama ollama ps
```

После ответа показывается `qwen3:8b` и GPU. Облачные модели отключены в compose (`OLLAMA_NO_CLOUD=1`), backend обращается только к локальному сервису `ollama:11434`. Наличие интернета на компьютере не означает облачный вызов. Для доказательства офлайн можно повторить короткий вопрос без сети, но только после сборки контейнеров и загрузки весов.

## Дополнительные проверки

- Скрыть и снова открыть настройки: переписка не исчезает.
- Отправить два раза быстро: пока запрос выполняется, повторная отправка заблокирована.
- Удалить **специально созданный тестовый чат**: нажать × возле него и подтвердить «Удалить навсегда». Это необратимо; не проверяйте на нужном диалоге. Другие чаты и результаты дня 26 остаются.
- Остановить только Ollama, отправить сообщение, убедиться, что USER остался с ошибкой. Запустить Ollama, нажать «Обновить», затем «Повторить ответ». Пользовательская реплика не должна дублироваться.
- Для обычной сдачи переполнять окно не нужно. У длинного диалога возможна явная ошибка окна 8192; сжатия истории в дне 27 нет.

## Готовые данные этой машины

Для основной проверки уже создан чат «День 27 — поездка в Казань» с тремя ходами и продолжением после перезапуска. Прямая ссылка: http://localhost:8483/#chat/0a04518d-5289-4b1f-8680-dbb055289f82.

Второй чат «День 27 — отдельный чат без контекста» демонстрирует изоляцию. Данные лежат в SQLite текущего Docker volume и доступны во внешнем браузере без импорта. После клонирования на другой компьютер их нужно создать заново.

Живые запросы на этой машине проверялись через HTTP API, используемый клиентом. Vue прошёл компонентные тесты. Автоматизация живого браузера была недоступна из-за ошибки запуска инструмента; визуальную проверку через UI необходимо выполнить по шагам выше. Не выдавайте компонентные тесты за завершённую браузерную проверку.
