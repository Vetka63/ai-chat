## Сеть и UI

Все три контейнера healthy. UI 8583 и backend 8582 опубликованы на 127.0.0.1. Ollama не публикуется на host. Windows portproxy слушает только IP ZeroTier, destination 127.0.0.1:8583. Firewall включён; создано правило на точные IP ПК/телефона и TCP 8583. Проверка HTTP с самого ПК через ZeroTier IP: 200, приватный status endpoint: enabled=true/authenticated=false.

Первый запуск сетевого скрипта выявил два нюанса: Restricted policy Windows блокировала .ps1; затем NetSecurity не принял имя интерфейса со скобками. Используется разовый дочерний процесс и точный LocalAddress вместо wildcard InterfaceAlias, широкого разрешения не добавляли.

Форма входа проверена в браузере на 390×844: scrollWidth=390, scrollHeight=844, горизонтального переполнения нет. Это проверка desktop-браузера с мобильным viewport, не реального Safari.

**На момент этой записи доступ и генерация с реального iPhone ещё не подтверждены: пользователь сообщил, что страница не открылась. Запросы телефона не обнаружены в Nginx logs. Продолжается диагностика ZeroTier/телефона; открытие адреса с ПК не выдаётся за проверку доступа по сотовой сети.**

## Что не обещаем

Домашний single-owner сервис, не production multi-tenant: один пароль, sessions/rate buckets в памяти, не Redis. HTTPS вне VPN, публичный доступ, cloud fallback, автоматическая настройка WAN/router, автологин Windows и гарантированный boot Docker Desktop до входа не входят в реализацию. ПК должен быть включён, Docker/ZeroTier работают, сна нет во время использования. Проверка iPhone нужна отдельно; общий Firewall отключать нельзя.
