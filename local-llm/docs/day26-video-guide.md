# День 26 — проверка в UI и запись видео

## Что сдаём

Локальная генеративная модель `qwen3:8b` работает в Ollama, доступна по HTTP и через CLI. Выполнены минимум три запроса: простой факт, задача с условиями, программирование. UI показывает фактические ответы и метрики, а SQLite позволяет открыть их из другого браузера.

## Проверка без комментариев на видео

1. Откройте http://localhost:8483 во внешнем браузере на весь экран.
2. Покажите заголовок «День 26», статус «Ollama … подключена» и выбранную `qwen3:8b`. В боковой панели видны размер и квантование модели.
3. Нажмите карточку «Короткий ответ». На экране появятся запрос и ожидаемый результат. Нажмите «Отправить локальной модели». Дождитесь текста, покажите Париж, статус «Ответ получен», input/output tokens и время.
4. Нажмите «Задача с условиями», отправьте её. Проверьте: 1500 × 0,8 = 1200; доставка 200; всего 1400 рублей.
5. Нажмите «Алгоритм и проверка», отправьте её. Проверьте hash map / dictionary, запрет использовать один элемент дважды, O(n), результаты [0,1], [0,1], None. Статус завершения сам по себе не проверяет правильность алгоритма.
6. Слева откройте три сохранённых запуска по очереди. Каждый содержит свой исходный запрос, модель, ответ и метрики.
7. Обновите страницу. Результаты остались: история хранится в backend, её не нужно импортировать в новый браузер.
8. В одном ответе раскройте «Параметры фактического запуска», покажите модель, температуру, reasoning и причину завершения `stop`. При необходимости скачайте MD.

Пустое поле максимума токенов оставляет настройку Ollama по умолчанию. Первый запрос обычно дольше из-за загрузки весов. Если появился `TRUNCATED`, ответ не завершён: увеличьте явно заданный лимит или очистите поле. При `FAILED` сохранён текст ошибки; не выдавайте такой запуск за успешный.

## CLI и HTTP — дополнительное подтверждение локального runtime

```powershell
cd F:\ai-advent-challenge\ai-chat\local-llm
docker compose -f compose.yml -f compose.gpu.yml exec ollama ollama list
docker compose -f compose.yml -f compose.gpu.yml exec ollama ollama run qwen3:8b --think=false "Сколько будет 2 + 2? Ответь коротко."
docker compose -f compose.yml -f compose.gpu.yml exec ollama ollama ps
```

Прямой HTTP-вызов Ollama в PowerShell:

```powershell
$body = @{
    model = 'qwen3:8b'
    messages = @(@{ role = 'user'; content = 'Назови столицу Франции.' })
    stream = $false
    think = $false
} | ConvertTo-Json -Depth 5
$response = Invoke-RestMethod http://localhost:11436/api/chat -Method Post -ContentType 'application/json; charset=utf-8' -Body ([Text.Encoding]::UTF8.GetBytes($body)) -TimeoutSec 300
$response.message.content
```

Запуски напрямую через Ollama CLI/API не попадают в SQLite приложения. Для истории в UI запрос должен пройти через `POST http://localhost:8482/api/v1/runs` или форму клиента.

При необходимости показать живую генерацию без интернет-подключения сначала загрузите веса и соберите контейнеры. Приложение не требует сети для генерации, но отключение интернета само по себе не обязательно для задания. Локальность подтверждается адресом runtime, установленными весами и процессом Ollama на GPU.

## Фактическая проверка 5 октября 2026

Три запроса отправлены кнопками UI в `http://localhost:8483`. Это не заготовленные ответы: результаты получены от установленной `qwen3:8b` и записаны backend в SQLite. Температура 0,7, reasoning выключен, максимум выходных токенов не задан.

| Проверка | Проверенное содержание | Время backend | Вход / выход, токены | ID запуска |
| --- | --- | --- | --- | --- |
| Простой запрос | «Столицей Франции является Париж.» | 4,675 с | 42 / 14 | `2f509f02-1a24-4b79-96cc-2795765e06f3` |
| Условия и расчёт | 1500 − 300 = 1200; доставка 200; итого 1400 рублей | 1,355 с | 100 / 117 | `86fc8238-fdec-4357-89ed-04f076ee69eb` |
| Two Sum | Поиск дополнения до записи элемента в словарь; ответы `[0, 1]`, `[0, 1]`, `None`; O(n) времени в среднем и O(n) памяти | 3,849 с | 129 / 386 | `39568aa8-71ac-401e-9696-cbbb03dbc467` |

У всех трёх записей `COMPLETED` и `done_reason=stop`, непустой ответ. Содержание проверено отдельно: статус завершения не является автоматической оценкой качества. Код Two Sum просмотрен, но автоматически не исполнялся.

Дополнительные проверки:

- CLI `ollama run` на запрос «Сколько будет 2 + 2?» вернул `4`.
- `ollama ps` показал `100% GPU`: используется RTX 4080 SUPER. Холодный CLI-запуск занял около 47 секунд; загрузка модели и первый прогрев делают его несопоставимым с последующими короткими запросами. Последующие запуски UI декодировали около 83–108 токенов/с. Это результаты данного компьютера, а не обещание такой скорости на любом устройстве.
- Только новый backend был перезапущен. Полные JSON трёх результатов до и после перезапуска совпали, и после обновления страницы все три результата появились в UI без повторной генерации.
- Пустой HTTP-запрос отклонён с HTTP 400 до вызова модели.
- Пройдены 10 backend-тестов и 5 клиентских тестов; сборка клиента проверяет TypeScript. Тесты адаптера используют локальный HTTP mock, а три запроса выше — настоящую модель.
- Старое RAG-приложение осталось доступно: его контейнеры и данные не изменялись.

Сохранённые ответы находятся в локальном Docker volume, не в Git. На этой машине можно открыть их слева и записать видео без новых вызовов. После клонирования репозитория на другом компьютере нужно загрузить модель и выполнить три запроса заново.
