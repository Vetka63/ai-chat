Ручная проверка выполнена чтением каждого пункта вместе с его цитатами. Это не автоматическая оценка judge. **Presence/exactness: 10/10; полнота и фактическая точность не объявляются 100%.** Есть повторения и упущенные нюансы. Они отмечены, а не скрыты высоким retrieval score.

В ответе undo-file цитируется упрощение книги «Git просто заменит его версией из последнего коммита». В общем случае `checkout -- <file>` восстанавливает из индекса; staged-содержимое может отличаться от HEAD. Это важный пример: точное цитирование источника само по себе не гарантирует универсальную техническую точность источника. Не расширяйте этот ответ на сценарии с staged-изменениями без уточнения. Термин книги «права доступа 160000» для submodule описывает специальный Git mode, не обычные Unix permission bits.

## Что обнаружено при проверке и исправлено

Первый reset-ответ имел восемь пунктов и девять точных цитат, но не содержал nullable `clarification:null`. Слишком жёсткая форма отклонила его. Валидатор теперь допускает отсутствие только этого поля для known, сохраняя все проверки evidence. Unknown по-прежнему требует непустое уточнение. Первый отказ сохранён в `data/day24-first-rejected.json`, последующий полный прогон прошёл без автоматических retry.

Первый live UI-тест ошибочно требовал `-u` именно в первом пункте, хотя первый корректно объяснял tracked по умолчанию. Проверка исправлена на наличие `-u` в полном ответе; повторный live grounded-тест прошёл и открыл цитату. Это исправление теста, не скрытая перестановка ответа модели.

Дополнительный вопрос «Как припрятать новый файл, который ещё ни разу не добавлял в Git?» с rewrite дал настоящий текст книги про git add, но ответ был **не на тот вопрос**. Это не было скрыто успешным substring-check. Инструкция усилена общей проверкой цели: нельзя заменять запрошенную операцию другой; пример в prompt про создание/удаление ветки, не про контрольный stash-вопрос. Повторный запрос вернул **UNKNOWN** с объяснением недостаточности найденных чанков. Два вызова (rewrite + generation), суммарно 1727 API tokens; rewrite не заменил исходный question. Неправильный предыдущий ответ сохранён локально в `data/day24-offtopic-rewrite.json`, исправленный отказ — в `data/day24-rewrite-result.json`.

После этой правки весь набор из десяти вопросов и четырёх gate-отказов повторно прошёл; final actual system message проверен на соответствие обновлённой инструкции. Первичный набор (60 пунктов/71 цитата) сохранён отдельно в `data/day24-before-focus-policy.json`. Prompt улучшает поведение, но не превращает детерминированный валидатор в semantic judge.
