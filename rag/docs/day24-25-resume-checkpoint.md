## Оставшиеся проблемы — не повторять массовый прогон без исправления

1. Source-only classifier путает общее определение команды с окружающей иллюстрацией. Классификация одного chunk как example может ошибочно заблокировать корректный `checkout -b`. Новый held-out fixture: `backend/src/test/resources/grounding/source-scope-branch-regressions.json`; его исправление не подтверждено.
2. Даже на одном пункте source-only иногда исчерпывает 16384 completion tokens без JSON; генератор иногда возвращает четыре цитаты при контракте 1–3.
3. Три проверки на пункт дают чрезмерную задержку/стоимость. Сначала переработать компактность и гранулярность контракта, сохранив защиту от потери условий и выдуманных цитат; не добиваться зелёного отчёта удалением отрицательных тестов.
4. Затем повторить затронутые наборы на неизменном кандидате: книжные вопросы, held-out cases, длинные диалоги и memory lifecycle. 66/66 не означает готовности всего чата.
