# Проверка дня 23: фильтр и rewrite

4 октября 2026 года проверены ветка `ai-challenge-day-23`, Docker-приложение, HTTP, браузер и реальные ответы DeepSeek. Требуемый пайплайн реализован. Сравнение показывает экономию фильтра на этом наборе, но не универсальное превосходство по качеству.

## Условия

Корпус — тот же русский Pro Git: commit `bef0ce52475e44b8c9d66d7ff8c6a03b37758a03`, snapshot `968b04948d80059aeba98b530ea4b611132f3ccfade4e56361c408b7bcb27d96`. STRUCTURAL индекс `c4f60fe8-4469-42e4-af66-d0ed289d0299`, размер 3000/300, 254 чанка. Локальные embeddings — `qwen3-embedding:0.6b`; генерация и rewrite — фактически возвращённая API модель `deepseek-flash`, temperature=0, thinking=disabled.

Основной эксперимент: десять [контрольных вопросов](../evaluation/day22-cases.json), RAW/FILTERED/REWRITE_FILTERED, candidate K=10, final K=5, threshold=0,65, budget=16000. Один общий rewrite и три ответа на вопрос — **40 платных вызовов**. Тестовый output cap=1200; дефолт приложения остаётся null. 29 ответов завершились stop, один — length; все десять rewrite завершились stop. Обрезанный ответ помечен, не считается полностью завершённым.

Дополнительно: два live UI test — **7 вызовов**, два разговорных вопроса — **8 вызовов**. Итого в проверках дня 23 сделано **55 LLM-вызовов**, без автоматических повторов. Три посторонних вопроса и preview/HTTP validation не требуют платной генерации. Полные результаты основного эксперимента сохраняются локально в игнорируемом `data/day23-live-results.json`; разговорные — в `data/day23-colloquial-results.json`.

Числа input/output — **API usage**, не локальная оценка. В группах порядок RAW / FILTERED / REWRITE_FILTERED. Бюджет не исключил дополнительных чанков.

`*` FILTERED/bisect: finish_reason=length, текст заканчивается посреди фразы. Основные шаги bisect изложены, но ответ не полный. Для самостоятельного опыта оставьте лимит пустым или увеличьте его. Обрезание не скрывается и не запускает новый платный запрос.

Общий rewrite: 2081 input + 311 output = 2392 токена. Расход всего основного сравнения — **118104 токена**, rewrite учтён ровно один раз. Сумма диапазонов оценок стоимости — **$0,01814169–0,03628338** по встроенному тарифному снимку; не подтверждённое списание. Дополнительные UI/разговорные вызовы в сумму не включены. Источник и механика тарифов — [отчёт дня 22](day22-test-results.md).

FILTERED сократил input на 4470 токенов (**13,8%**) относительно RAW. REWRITE_FILTERED сократил input генерации на 10,1%, но **с учётом собственного rewrite input** экономия только **3,7%**. Output зависит от длины ответа; его нельзя считать постоянным. При отдельном использовании FILTERED затраты rewrite отсутствуют.

Среднее время именно генерации: RAW 4287,7 мс, FILTERED 4207,2 мс, REWRITE_FILTERED 4105,1 мс. Это не время всей цепочки: общий rewrite и retrieval сюда не входят. Параллельность, cache и один запуск на вопрос не позволяют заявлять статистический выигрыш в скорости.

## Ручная проверка содержания

Проверены основные ожидания, а не каждое дополнительное предложение и не точность всех автосгенерированных цитат. Document hit=10/10 для каждого режима не означает semantic correctness.

| Вопрос | Вывод по трём режимам |
| --- | --- |
| reset | Основные soft/mixed/hard и риск изложены верно. Дополнительные утверждения о reset с путём в RAW/FILTERED неточны: обычный reset с путём меняет индекс, не рабочий файл. Фильтр этого не исправил. |
| rebase | Различие историй и риск переписывания общей истории есть во всех режимах. RAW/FILTERED при одинаковом контексте совпали; выигрыш rewrite не доказан. |
| stash | Все различают -u/untracked и -a/ignored. Отсечение одного слабого чанка снизило input без потери основного вывода. |
| fetch-pull | Все различают получение и получение с интеграцией. Threshold не изменил final контекст. |
| undo-file | Команда и риск есть во всех ответах. RAW обобщает восстановление как HEAD, FILTERED также неоднозначен; REWRITE_FILTERED отдельно уточняет индекс против HEAD. Наблюдение одного запуска, не гарантия превосходства rewrite. |
| add-snapshot | Во всех ответах в коммит идёт версия на момент add. FILTERED сохранил один достаточный чанк; rewrite вернул пять, не улучшив главный результат. |
| branch-pointer | Все объясняют ссылку на commit и HEAD. После фильтра осталось четыре чанка без потери основного смысла. |
| git-objects | Blob/tree/commit и связи есть во всех режимах. RAW/FILTERED совпали; эффекта отбора здесь нет. |
| bisect | Good/bad, проверка промежуточных коммитов и reset есть во всех ответах. FILTERED обрезан тестовым cap, его нельзя считать законченным. |
| submodule | Отдельный repository, commit pointer и .gitmodules есть во всех режимах. Фильтр не изменил число чанков. |

Главный измеримый результат — управляемый отбор и сокращение контекста, возможность видеть как улучшения, так и ухудшения. Ошибки в дополнительных утверждениях показывают, зачем дню 24 нужна отдельная работа с доказательствами, а не просто увеличение similarity.

## Нерелевантные и разговорные вопросы

| Посторонний вопрос | Лучший cosine | RAW / FILTERED выбранных чанков |
| --- | --- | --- |
| Погода завтра в Самаре | 0,3590 | 5 / 0 |
| Рецепт борща | 0,3844 | 5 / 0 |
| Победитель следующего чемпионата мира по футболу | 0,3883 | 5 / 0 |

На этих примерах 0,65 отсёк весь посторонний контекст. Проверка — preview без rewrite и генерации. Порог не обучен на большой независимой выборке; похожий на Git, но не покрытый книгой вопрос всё ещё может пройти. Это не полноценный детектор галлюцинаций.

Разговорные вопросы дали шесть завершённых ответов без ошибок. «Временно отложить новые файлы»: 5/4/5 чанков, rewrite повысил лучший score с 0,6630 до 0,6801, но все ответы уже правильно называли stash -u. «Добавил файл в подготовленные, затем снова отредактировал»: 5/5/5 чанков; лучший score с rewrite снизился с 0,7586 до 0,7271, главный факт сохранился. Больший score и rewrite не самоцель.
