# common

Минимальная общая инфраструктура, не контейнер всех бизнес-классов.

- `Hashing`: SHA-256 строк канонического текста и конфигурации.
- `LabException`: доменный code/message/HTTP status.
- `ApiError`: стабильный JSON ошибки для клиента.
- `RestAdvice`: перевод validation/body/domain exceptions в API errors; неожиданная ошибка логируется на сервере, пользователю возвращается безопасное сообщение.

Новая функция помещается сюда только если действительно общая для нескольких доменов. Chunking, corpus, embeddings и retrieval остаются в своих пакетах.
