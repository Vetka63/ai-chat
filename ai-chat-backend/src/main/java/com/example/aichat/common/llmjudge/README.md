# LLM as judge

Общий пакет содержит только расширяемый контракт `LlmJudge<I, O>` и
`LlmJudgeRegistry`. Он не знает о конкретных заданиях, промптах или DTO.

Каждая задача реализует собственный judge рядом со своим доменом, объявляет
стабильный `type`, входную команду и тип результата. Registry проверяет
уникальность типов и безопасно выдаёт реализацию контроллеру задачи.
