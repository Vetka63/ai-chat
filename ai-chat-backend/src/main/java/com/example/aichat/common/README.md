# Common

Здесь находятся стабильные расширяемые контракты и модели, которые действительно
используются несколькими задачами: профили, LLM port, input/output policy,
validators и LLM-as-judge registry.

`common` никогда не импортирует `task`. Если класс используется только одной
задачей, он остаётся внутри её вертикального среза.
