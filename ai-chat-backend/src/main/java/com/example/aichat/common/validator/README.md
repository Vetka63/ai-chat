# Validation

Модуль содержит подключаемые проверки запроса до основной генерации.

- `RequestGuard` — интерфейс одной проверки.
- `RequestGuardRegistry` — выбирает реализацию по `request_guard.type`.
- `task/day2/recipe/validator` — реализация LLM-классификатора кулинарных запросов.

Профиль управляет инструкцией, `max_tokens` и `max_attempts`. Чтобы добавить
валидатор, реализуйте `RequestGuard` внутри задачи, задайте уникальный `type`,
добавьте тесты и укажите тип в YAML. Recipe-классификатор оценивает последнее
пользовательское сообщение; из истории передаётся только минимальный контекст,
необходимый для продолжений вроде «а без лука?».
