# Bootstrap

Модуль композиции связывает независимые backend-домены после создания Spring
beans. Он может зависеть от прикладных модулей, но ни один домен не должен
импортировать `bootstrap`.

`AgentConfigurationVerifier` при запуске проверяет, что каждый YAML-профиль
ссылается на зарегистрированные request guard и output policy, а для каждого
нестандартного `experience_type` существует валидатор его `feature_config`.
Ошибочная конфигурация останавливает запуск приложения, а не проявляется во
время пользовательского запроса.
