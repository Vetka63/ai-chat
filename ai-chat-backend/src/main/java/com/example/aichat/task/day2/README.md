# День 2: структурированный ответ и семантическая проверка

Домен объединяет обе части задания Дня 2:

- `recipe` — семантическая проверка запроса и строгий JSON-рецепт;
- `answer` — строгий JSON-ответ общего назначения для универсального профиля.

Специфичные реализации подключаются к общему chat pipeline через
`RequestGuardRegistry` и `OutputPolicyRegistry`. Идентификаторы `recipe-intent`,
`recipe-json` и `answer-json` являются стабильной связью с YAML-профилями.

Новый формат добавляется отдельной реализацией `OutputPolicy`; общий chat-сервис
находит её через `OutputPolicyRegistry` по настройке response mode.
