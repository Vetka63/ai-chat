# Recipe

Домен ограничивает профиль рецептов кулинарными запросами. Сейчас он содержит
`RecipeIntentRequestGuard`, который классифицирует только последнее сообщение,
и enum допустимых вердиктов. Проверка подключается к профилю через
`request_guard.type`, поэтому её можно менять независимо от чата и output-policy.
