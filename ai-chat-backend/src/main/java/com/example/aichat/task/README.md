# Tasks

Каталог содержит вертикальные срезы учебных заданий, которым недостаточно общих
механизмов чата, validators или output policies.

Каждая новая задача получает собственный вертикальный срез, при необходимости
`dayN/<feature>`, и не расширяет классы предыдущих дней. Повторно используемый
контракт переносится в `common` только после появления реального потребителя.

Текущие вертикальные задачи:

- `day2` — управляемый и структурированный ответ, включая кулинарную валидацию;
- `day3/reasoning` — сравнение четырёх способов рассуждения и LLM-as-judge;
- `day4/temperature` — три независимых ответа на одну задачу при `0`, `0.7` и
  `1.2` без истории диалога.
