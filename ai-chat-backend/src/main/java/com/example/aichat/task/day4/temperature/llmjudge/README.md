# LLM-судья температурного эксперимента

Этот пакет отвечает только за автоматическое сравнение уже полученных ответов
Дня 4. Генерация четырёх вариантов остаётся в `temperature/service`, а судья
вызывается отдельным запросом и не запускается автоматически.

## Поток

```text
POST /api/temperature-experiments/judge
  -> TemperatureJudgeController
  -> LlmJudgeRegistry
  -> TemperatureJudgeService
       -> проверяет задачу и идентификаторы вариантов
       -> сортирует варианты в порядке YAML
       -> заменяет названия и температуры кодами A, B, C, D
       -> вызывает deepseek-v4-pro с temperature = 0
       -> проверяет JSON, оценки 0..10 и наличие всех кандидатов
       -> при повреждённом JSON делает одну повторную попытку
       -> возвращает исходные названия, температуры и метрики
```

## Почему ответы обезличиваются

Если передать судье подпись `temperature = 2.0`, модель может заранее считать
ответ менее точным. Поэтому во входном JSON присутствуют только исходная задача,
коды `A`–`D` и тексты ответов. Соответствие кодов температурам остаётся внутри
Java-сервиса и восстанавливается только после проверки результата.

## Критерии

- `accuracy` — фактическая и логическая точность;
- `creativity` — оригинальность и практическая ценность идей;
- `instructionFollowing` — соблюдение требований исходного запроса;
- `diversityScore` — разнообразие всего набора ответов.

Каждая оценка должна быть целым числом от 0 до 10. Победитель выбирается по
содержанию; инструкция отдельно указывает, что точность и соблюдение запроса
важнее декоративного стиля.

## Устойчивость ответа

DeepSeek должен вернуть JSON заданной схемы. Сервис отклонит ответ, если JSON
повреждён, кандидат потерян или продублирован, победитель неизвестен, текстовое
объяснение пустое либо оценка вышла за диапазон. После первой ошибки выполняется
одна повторная попытка с увеличенным лимитом. Если она тоже неуспешна, клиент
получает контролируемую ошибку `502`.

Ручные оценки пользователя не отправляются судье. Это позволяет независимо
сравнить собственное мнение с рекомендацией модели.
