# День 3: reasoning experiment

Модуль выполняет одну задачу четырьмя стратегиями и возвращает результаты рядом.

- `controller/dto` — контракт запуска эксперимента.
- `service` — выбор стратегий, параллельный запуск и агрегация метрик.
- `strategy` — direct, step-by-step, meta-prompt и expert-panel.
- `model` — контекст, результаты, эксперты и метрики.
- `config` — типизированное чтение `feature_config` профиля.
- `llmjudge` — отдельный поддомен автоматического сравнения.

Промпты и лимиты всех стратегий находятся в
`resources/agents/day3-reasoning.yml`. Новый способ реализует
`ReasoningStrategyExecutor`; registry в сервисе проверяет полноту и дубликаты.
История и серверное хранение экспериментов намеренно отсутствуют.

Ответы четырёх стратегий создаются моделью профиля, а автоматическая оценка
выполняется отдельно моделью `deepseek-v4-pro`. Модель судьи задаётся в
`feature_config.judge.llm`, поэтому её можно менять без влияния на генераторы.
