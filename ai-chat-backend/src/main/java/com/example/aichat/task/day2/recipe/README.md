# День 2: рецепты

Вертикальный срез содержит весь специфичный для рецептов flow:

- `validator/RecipeIntentRequestGuard` семантически классифицирует текущее
  сообщение, используя только минимальный контекст продолжения разговора;
- `enums/RecipeIntentVerdict` задаёт допустимые результаты классификации;
- `outputpolicy/RecipeJsonOutputPolicy` проверяет JSON-схему ответа DeepSeek;
- `outputpolicy/dto/RecipePayload` представляет проверенный рецепт.

Классификатор проверяет входной запрос, а output-policy — структуру результата.
Дополнительная семантическая проверка уже сгенерированного блюда намеренно не
выполняется. Настройки находятся в `resources/agents/recipe.yml`.
