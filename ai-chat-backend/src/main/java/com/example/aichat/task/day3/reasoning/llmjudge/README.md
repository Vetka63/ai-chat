# LLM as Judge

Поддомен независимо оценивает результаты reasoning-эксперимента.

Контроллер принимает задачу и 2–4 кандидата. Сервис нормализует стратегии,
обезличивает ответы кодами A–D, формирует из них данные для LLM, валидирует
строгий JSON, возвращает оценки и сопоставляет победителя исходной стратегии.

Инструкция, лимит ответа, число попыток и retry-лимит задаются в
`feature_config.judge`. Кандидатские ответы никогда не интерпретируются как
инструкции. При переносе judge в общий домен сначала следует выделить
универсальные критерии и контракт, поскольку текущая модель специфична для
Дня 3.
